## Sobre mí

Graduado en Ingeniería de Telecomunicación (especialidad Telemática) por la Universidad Rey Juan Carlos, enfocado en desarrollo backend y sistemas basados en datos. Mi Trabajo de Fin de Grado, WebBuilder-TFG, combina Django con IA generativa para generar automáticamente aplicaciones web desplegables a partir de cualquier API pública — calificación 9,9, propuesto para Matrícula de Honor. Recientemente completé unas prácticas de ingeniería en Bosch, trabajando con pipelines de datos de producción, dashboards y automatización de procesos, y ahora sigo ampliando esa base con ciberseguridad, cloud e ingeniería asistida por IA.

## Proyectos Destacados

### [WebBuilder-TFG](https://github.com/AlejandroTejero/WebBuilder-TFG) ![nota](https://img.shields.io/badge/9.9%20%C2%B7%20Honores-854F0B?style=flat&logoColor=white)

Convierte cualquier API pública (JSON/XML/CSV) en un proyecto Django completo y desplegable. Un LLM analiza el dataset, propone el esquema de datos y genera el código. Incluye autenticación OAuth (Google/GitHub), un editor de código asistido por IA, versionado de sitios generados y despliegue automatizado con monitorización de contenedores. Presentado en la 1ª Jornada de Software Libre e IA de la URJC.
